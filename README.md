# Genshin Impact Wish Simulator

A web-based Genshin Impact wish simulator that lets users configure their resources, pity, banners, characters, and pulling goals, then run Monte Carlo simulations through a FastAPI backend.

**[Live Demo](https://gacha-simulator-vtbh.onrender.com/)** · **[Backend API](https://github.com/luxuaniside/gacha-simulator-api)**

## Features

- **Resource management** — Configure Primogems, Intertwined Fates, Genesis Crystals, and Starglitter.
- **Pity configuration** — Set pity counters, guarantee states, Capturing Radiance, and Epitomized Path.
- **Banner management** — Create and edit character and weapon banners.
- **Goal management** — Define pulling goals, target items, quantities, and priorities.
- **Simulation settings** — Configure iterations, Starglitter refunds, and goal completion behavior.
- **Simulation results** — Track progress and view aggregated results.
- **Data import** — Import supported character and weapon data from GOOD/Kamera exports.
